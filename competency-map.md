# Competency Map

The purpose of this map is to track depth, not just exposure. A concept is not "learned" because it has been encountered once.

## Proficiency levels

| Level | Standard |
|---|---|
| **Explain** | Explain the intuition, purpose, and basic mechanics in plain language. |
| **Build** | Implement a correct basic version and inspect its outputs. |
| **Apply** | Identify an appropriate sports problem, use the method with real data, and interpret the result. |
| **Defend** | Justify the method against alternatives, explain assumptions and failure modes, validate it, quantify uncertainty, and connect it to a decision. |

## Pillar rubric

| Pillar | Explain | Build | Apply | Defend |
|---|:---:|:---:|:---:|:---:|
| Measurement | ☐ | ☐ | ☐ | ☐ |
| Prediction | ☐ | ☐ | ☐ | ☐ |
| Player valuation | ☐ | ☐ | ☐ | ☐ |
| Causal inference | ☐ | ☐ | ☐ | ☐ |
| State & value modeling | ☐ | ☐ | ☐ | ☐ |
| Decision science | ☐ | ☐ | ☐ | ☐ |
| Spatial & tracking analytics | ☐ | ☐ | ☐ | ☐ |

The boxes are intentionally manual. Completion should be supported by evidence rather than self-assigned casually.

## Evidence standard

For **Apply** or **Defend**, link to evidence when possible:

- an applied study
- a production metric or model
- a documented analysis
- a validation report
- a presentation or decision memo
- a model critique
- a reproducible notebook or script in a sport-specific project

## Five questions for every method

1. What problem does this solve?
2. Why would I not use something simpler?
3. What assumptions am I making?
4. How do I validate it?
5. How does it change a sports decision?

If those five answers are weak, the method probably has not reached the Defend level yet.

## Suggested concept inventory

### Measurement
- rates and denominators
- context adjustment
- opponent-strength adjustment
- Elo and rating systems
- reliability and sample size
- metric design

### Prediction
- linear and logistic regression
- regularization
- gradient boosting
- calibration
- cross-validation
- temporal validation
- feature engineering

### Player valuation
- adjusted plus-minus / RAPM
- hierarchical models
- Bayesian shrinkage
- replacement level
- aging and development curves
- uncertainty in player estimates

### Causal inference
- counterfactuals
- causal DAGs
- confounding
- matching
- propensity scores
- inverse-probability weighting
- heterogeneous treatment effects
- mediation
- sensitivity to unmeasured confounding

### State & value modeling
- expected value
- Markov models
- EPA / EPV
- state definition
- action value
- credit assignment

### Decision science
- simulation
- Monte Carlo methods
- optimization
- expected utility
- constraints
- scenario analysis
- risk and uncertainty

### Spatial & tracking analytics
- coordinate systems
- spatial features
- trajectories
- pressure and spacing
- spatiotemporal models
- embeddings
- computer vision / tracking
