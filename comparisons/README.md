# Method Comparisons

Knowing methods individually is not enough. This folder focuses on **choice**: when two plausible approaches answer different questions, make different assumptions, or trade interpretability for flexibility.

Each comparison should answer:

1. What problem does each method solve?
2. Where do they overlap?
3. What assumptions differ?
4. What validation evidence matters?
5. What sports decision would make one preferable?
