# Glossary

Short working definitions. Detailed explanations belong in concept pages.

- **Calibration** — Agreement between predicted probabilities and observed frequencies.
- **Causal effect** — The change in an outcome attributable to changing a treatment/intervention.
- **Confounder** — A variable that affects both treatment/exposure and outcome and can bias a causal comparison.
- **Counterfactual** — The outcome that would have occurred under a different treatment or decision.
- **Credible interval** — A Bayesian interval describing posterior uncertainty about a parameter or quantity.
- **DAG** — Directed acyclic graph used to represent assumed causal relationships among variables.
- **EPA** — Expected points added; change in expected future value associated with an action or state transition.
- **EPV** — Expected possession value; expected future value of a possession given the current state.
- **Estimand** — The exact quantity an analysis is trying to estimate.
- **Feature engineering** — Constructing model inputs from raw data using statistical and domain knowledge.
- **Gradient boosting** — An ensemble method that sequentially adds weak learners, usually trees, to improve prediction.
- **Hierarchical model** — A model where units such as players or teams have parameters drawn from shared population-level distributions.
- **Likelihood** — The probability model connecting parameters to observed data.
- **Mediator** — A variable on the causal pathway through which a treatment affects an outcome.
- **Monte Carlo simulation** — Repeated random simulation used to approximate outcome distributions under specified assumptions.
- **Partial pooling** — Estimation that allows groups to differ while borrowing information across groups.
- **Posterior** — Bayesian distribution for an unknown quantity after combining prior information and observed data.
- **Prior** — Bayesian representation of information or assumptions about an unknown quantity before current data are incorporated.
- **Propensity score** — Probability of receiving a treatment given observed pre-treatment covariates.
- **RAPM** — Regularized adjusted plus-minus; player-impact estimation using adjusted plus-minus with regularization to stabilize correlated/noisy estimates.
- **Regularization** — Penalizing model complexity or extreme parameter values to improve stability and generalization.
- **Shrinkage** — Pulling noisy estimates toward a common or prior value, usually more strongly when evidence is weak.
- **State-space model** — A model describing an unobserved state that evolves through time and generates observed measurements.
- **Treatment** — The intervention, exposure, or decision being evaluated in a causal analysis.
