# Applied Analytics Project Template

Use this template for substantial studies. The goal is to force clarity before modeling begins.

## 1. Sports question

What does the coach, analyst, or decision-maker actually want to know?

## 2. Analytical question

Translate the sports question into something estimable.

## 3. Decision connection

What decision could change if the answer is different?

## 4. Unit of analysis

Examples:
- rally
- possession
- shift
- shot
- player-game
- team-match

## 5. Target / estimand

What exact quantity are we trying to estimate?

Examples:
- probability
- expected value
- treatment effect
- latent player ability
- ranking

## 6. Data-generating process

Describe how observations enter the dataset and how sports decisions generate the recorded variables.

## 7. Candidate methods

Start with the simplest credible baseline, then justify added complexity.

## 8. Assumptions

List assumptions explicitly rather than leaving them implicit in code.

## 9. Validation plan

Before fitting the final model, specify how it will be challenged.

Examples:
- temporal holdout
- calibration
- posterior predictive checks
- balance diagnostics
- sensitivity analysis
- simple baseline comparison

## 10. Uncertainty

How will uncertainty be represented and communicated?

## 11. Results

Separate:
- observed facts
- model estimates
- causal claims
- assumptions-dependent interpretations

## 12. Practical interpretation

Explain the result in sports language.

## 13. Recommendation

What, if anything, should change?

## 14. Limitations

What would make the conclusion wrong or weaker than it appears?

## 15. Research vs. production decision

Choose an endpoint:

- research conclusion only
- documented metric
- recurring report
- production metric
- production model
- simulation / decision-support tool

Explain why.

## 16. Evidence for competency map

Which pillar(s) and proficiency level(s) does this project support?
