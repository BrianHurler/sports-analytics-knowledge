# Description → Prediction → Causation → Decision

These are different analytical jobs. Confusing them is one of the easiest ways to produce a technically impressive but decision-poor analysis.

## 1. Description

**Question:** What happened?

Examples:
- attack efficiency against 1900+ Elo
- controlled-entry success rate
- shot quality by game state

Descriptive work is often the right answer. It becomes a problem only when descriptive differences are interpreted as causes.

## 2. Prediction

**Question:** What is likely to happen?

Examples:
- expected attack success against a 1900-Elo opponent
- probability a shot becomes a goal
- next-season scoring projection

Prediction is judged primarily by out-of-sample performance and calibration.

## 3. Causation

**Question:** What would happen if we changed something?

Examples:
- would increasing on-two usage improve rally-win probability?
- does a more aggressive serving strategy improve net point scoring?
- does a tactical deployment change player outcomes?

Causal inference requires a defensible counterfactual and careful treatment of confounding.

## 4. Decision

**Question:** What should we do?

Examples:
- what serve strategy should we use against a given receiver?
- what on-two frequency maximizes expected scoring?
- which roster move maximizes expected wins under constraints?

Decision analysis combines estimates with objectives, constraints, uncertainty, and risk.

## The progression

A mature analytics program often moves through:

**description → prediction → causation → optimization**

But not every problem needs to progress all the way to the right. A clear descriptive metric can be the correct endpoint; a causal study can produce durable organizational knowledge without becoming a production system.
