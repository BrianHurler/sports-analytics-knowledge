# Decision Maps

This folder connects sports questions to analytical methods. The goal is not to identify the fanciest model; it is to identify the simplest defensible approach that answers the actual decision question.

Use these maps before choosing a method.

## Core sequence

1. Start with the sports decision.
2. Define the analytical question.
3. Define the estimand or prediction target.
4. Understand how the data were generated.
5. Establish a simple baseline.
6. Choose a method appropriate to the question.
7. Validate the result and quantify uncertainty.
8. Translate the result back into a sports decision.
9. Decide whether the work belongs as research, recurring analysis, or production.
